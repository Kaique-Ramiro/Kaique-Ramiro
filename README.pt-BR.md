## 🚀 Projetos em destaque

### 🎬 TVScore — Recomendação de filmes e séries com IA

Plataforma para descobrir, avaliar e comentar filmes e séries. Fui responsável pelos **serviços de inteligência artificial em Python**, incluindo recomendações personalizadas e análise de sentimentos de avaliações.

- **IA e recomendações:** Python, FastAPI, Sentence Transformers e classificação multilíngue de sentimentos
- **Dados e integrações:** MySQL, API TMDB e integração com backend em Java
- **Funcionalidades:** Recomendações por gênero, ranking personalizado e análise de sentimentos dos comentários

### 📚 Biblio Tec — Biblioteca digital

Projeto web para consulta de livros e gerenciamento de **favoritos e reservas**.

- **Tecnologias:** HTML, CSS e JavaScript
- **Funcionalidades:** Busca de livros, detalhes e reservas

### 📦 Sistema de Estoque — Projeto acadêmico

Sistema acadêmico voltado ao **controle de estoque e integração com banco de dados**.

- **Tecnologias:** Java, MySQL, SQL e JDBC
