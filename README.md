### Sobre Mim

Sou estudante de **Ciência de Dados na FATEC** e **Técnico em Desenvolvimento de Sistemas pelo SENAI**, com interesse em tecnologia, programação, banco de dados e análise de dados.

Busco desenvolver soluções que unam **programação e análise de dados**, transformando informações em resultados úteis para a tomada de decisões.

- 📊 Formação em **Excel Avançado** pelo SENAI.

- 🐍 Conhecimentos em **Python e SQL**.

- 💡 Interesse em **Data Analytics, Ciência de Dados, Banco de Dados e Desenvolvimento de Software**.
