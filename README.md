## 🚀 Featured projects

### 🎬 TVScore — AI-powered movie & TV recommendations

A platform for discovering, rating and reviewing movies and series. I worked on the **Python AI services**, including personalized recommendations and sentiment analysis of user reviews.

- **AI & recommendations:** Python, FastAPI, Sentence Transformers and multilingual sentiment classification
- **Data & integration:** MySQL, TMDB API and integration with a Java backend
- **Features:** Genre-based recommendations, personalized ranking and review sentiment analysis

### 📚 Biblio Tec — Digital library

A web project for browsing books and managing **favorites and reservations**.

- **Stack:** HTML, CSS and JavaScript
- **Features:** Book search, details and reservations

### 📦 Inventory Management System — Academic project

An academic system focused on **inventory control and database integration**.

- **Stack:** Java, MySQL, SQL and JDBC
